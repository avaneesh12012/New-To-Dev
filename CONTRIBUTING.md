# ❤️ Welcome to the New-To-Dev Family!

First off, **thank you from the bottom of our hearts for being here.**  

Whether you found this project while looking for your very first open-source Pull Request or you are an experienced developer wanting to give back to the community, your time and effort mean the world to us.  

We believe that learning Computer Science shouldn't feel like deciphering an ancient secret. It should feel like opening a door to endless possibilities. Every single fix, translation, typo correction, and feature you add helps a beginner somewhere in the world take their first step into technology without feeling lost or overwhelmed.  

You don't need to be a coding genius to contribute here. Your perspective, your enthusiasm, and your willingness to help are more than enough.

## 🤝 Our Code of Conduct: Leading with Kindness

We are committed to making `New-To-Dev` a safe, encouraging, and warm environment for everyone, regardless of background, skill level, or experience.

| 🌟 Principle | 💬 What It Means |
| :---: | :--- |
| 💞 **Empathy First** | We were all total beginners once. Never judge a question or a piece of code. |
| 🗣️ **Constructive Feedback** | If someone makes a mistake, guide them with kindness and patience. |
| ⏳ **Patience** | People contribute in their free time. Give maintainers grace and time to respond. |
| 🚫 **Zero Intimidation** | No question is "too stupid." Ask anything, anytime! |

## 🗺️ Step-by-Step Contribution Guide

If you've never submitted a Pull Request before, don't worry! Follow these simple steps and you'll have your name on the project in no time.

### 📌 Step 1: Fork the Repository
Because external contributors don't have direct write access to the main repo, you'll first make a personal copy.  
1. Look at the **top-right corner** of this GitHub page and click the **Fork** button.  
2. Select your account to create a copy under your name (e.g., `github.com/your-username/New-To-Dev`).

### 📌 Step 2: Clone Your Fork Locally
Open your terminal (Command Prompt, PowerShell, Git Bash, or VS Code terminal) and run:


# Clone your personal fork to your computer
`git clone https://github.com/YOUR-USERNAME/New-To-Dev.git`

# Move into the project folder
`
cd New-To-Dev
`

### 📌 Step 3: Create a New Branch
`
git checkout -b your-feature-name
`

### 📌 Step 4: Make Your Changes & Commit
`
git add .`
`git commit -m "`✨ Add: your awesome contribution"


### 📌 Step 5: Push & Create a Pull Request
`
git push origin your-feature-name
`
Then go to your fork on GitHub and click **"Compare & Pull Request"**.

## 🚀 Quick Start for Absolute Beginners

> 🆕 **New to GitHub?** No problem! Here's everything you need to get started:

1. **Create a GitHub account** (if you don't have one)
2. **Fork this repository** (click the Fork button above)
3. **Make your changes** (even a single typo fix helps!)
4. **Submit a Pull Request** (we'll guide you through it)

<details>
<summary>📖 <strong>Click here for a detailed beginner's guide</strong></summary>

<br>

**What is Open Source?**
Open source means the code is publicly available for anyone to view, use, modify, and distribute. It's like a public library where everyone can contribute!

**Why Contribute?**
- Build your portfolio
- Learn from experienced developers
- Give back to the community
- Make friends worldwide
- Gain real-world experience

**No Contribution is Too Small!**
- Fix a single typo
- Improve a comment
- Add a translation
- Report a bug
- Suggest an improvement
